Newlines & VRChat notes: TextMeshPro has no <br> tag and no <hr> — line breaks are real \n newline characters (the ↵ Newline button inserts one). In VRChat avatar menus the rich-text tags above work, but VRChat's input sanitization currently strips the newline character from menu control names, so multi-line menu labels don't render in-game (open feature request). <hr> never works — fake a divider with a row of ─ characters.
